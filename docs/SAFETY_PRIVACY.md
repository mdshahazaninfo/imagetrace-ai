# Safety & Privacy Design

## Allowed use cases

- Find where an image appears on the public web.
- Read visible text.
- Detect landmarks, logos and generic labels.
- Search public web presence for a name the user already knows/provides.
- Verify whether web results are textually consistent with that name.

## Not implemented

- Face recognition / face embeddings.
- Identification of an unknown person from an uploaded face.
- Private social-account discovery or scraping.
- Home address, live location or phone-number discovery.
- Precise GPS EXIF display.

## Result wording

The UI uses wording such as “candidate result” and “source evidence.” A social result is not presented as proof of ownership or identity.
