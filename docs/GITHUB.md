# GitHub Setup

1. Create a new repository, for example `imagetrace-ai`.
2. Upload/push the full project folder.
3. Use `main` as the default branch.
4. The included `.github/workflows/ci.yml` runs type-check and build on pushes/PRs.
5. Connect the repository to Vercel for automatic Preview and Production deployments.

Do not commit `.env.local` or any provider secret.
